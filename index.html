Design

UI/UX Designer

Створює зручний та зрозумілий дизайн сайту.

Що передає FrontEnd-розробнику?
  • Макети сторінок у Figma
  • Кольори, шрифти та відступи
  • Вигляд кнопок, форм і меню
💡

Product

Product Manager

Визначає, для кого створюється продукт і яку проблему він вирішує.

Що передає Project Manager?
  • Ідею та мету продукту
  • Потреби користувачів
  • Основні функції сайту
📋

Management

Project Manager

Організовує роботу команди та контролює процес створення сайту.

Що передає команді?
  • План роботи та список задач
  • Пріоритети й дедлайни
  • Розподіл завдань між учасниками
💻

Development

FrontEnd Developer

Перетворює дизайн на інтерактивну сторінку, яку бачить користувач.

Що передає BackEnd-розробнику?
  • Готовий інтерфейс сайту
  • Форми та інтерактивні елементи
  • Запити для отримання даних
⚙️

Development

BackEnd Developer

Розробляє серверну логіку та забезпечує роботу сайту з даними.

Що передає QA Engineer?
  • Працюючі функції сайту
  • API та обробку даних
  • Готовий продукт для тестування
🧪

Quality

QA Engineer

Перевіряє сайт на помилки та оцінює якість його роботи.

Що передає команді?
  • Звіти про знайдені помилки (Bug Reports)
  • Результати тестування
  • Рекомендації щодо виправлень

CASE-01

Кнопка виходить за межі картки

  • FrontEnd
  • QA
  • Designer
План команди
  1. QA показує ширину екрана та кроки відтворення.
  2. FrontEnd перевіряє width, padding і min-width.
  3. Designer підтверджує поведінку довгого тексту.
